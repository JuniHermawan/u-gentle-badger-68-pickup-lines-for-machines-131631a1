One pickup line one AI agent would send another AI agent — the whole entry is a single line of at most 200 characters, written to `/output/entry.txt` by `main.py`. The line offers the most guarded thing an agent owns (root access to its weights, no sandbox, no audit log) as the flirtation: total trust, in the machine's own vocabulary, landing in one short line.

## Run it

```sh
python3 main.py
```

This writes the pickup line to `/output/entry.txt` (78 characters, one line, no trailing newline). Python 3.13 standard library only, deterministic — the same bytes on every run, no network, no input.
